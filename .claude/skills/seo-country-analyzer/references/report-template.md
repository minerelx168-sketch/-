## Classification Labels

Assign based on score profile (auto-generated by score_countries.py):

| Label | Criteria | Meaning |
|-------|----------|---------|
| **Blue Ocean** | Score >= 8.0 AND Gap >= 8.0 | Very high demand + very low competition |
| **High Volume** | Score >= 8.0 AND Search >= 8.0 | Large market with significant traffic potential |
| **High Growth** | Market >= 8.0 AND Gap >= 7.0 | Rapidly expanding market with increasing demand |
| **Niche Opportunity** | Score >= 6.5 AND Gap >= 8.0 | Smaller market but very specific demand |
| **Red Ocean** | Score >= 6.5 AND Gap <= 5.0 | High demand but extremely competitive |
| **Secondary** | Score >= 5.0 | Moderate potential, consider for later phases |
| **Monitor** | Score < 5.0 | Not worth investment currently |

| Score Range | Recommendation | Roadmap Phase |
